# ФудТех — конфигурация 1С:Предприятие

Демонстрационная производственно-торговая система на платформе 1С:Предприятие 8.3,
разработанная в 1С:EDT для вымышленной компании «ФудТех» (пищевое производство).

Проект создан как портфолио-работа для демонстрации навыков разработки на платформе 1С.

## Стек

- 1С:Предприятие 8.3 (платформа 8.5.1.1150)
- 1С:EDT — разработка конфигурации в формате EDT (не в Конфигураторе)
- Git — версионирование в формате исходников (XML)

## Границы MVP

Реализован сквозной бизнес-цикл: закупка → склад → производство → продажа.

Упрощения первой версии:
- одна валюта учёта
- себестоимость считается как сумма материалов + прямые затраты, без деления по статьям
- без сравнения цен поставщиков и тендерной логики

## Структура репозитория

- `src/Configuration` — исходники конфигурации в формате EDT
- `DT-INF` — служебные файлы выгрузки/загрузки
- `docs/` — документация проекта, ADR
